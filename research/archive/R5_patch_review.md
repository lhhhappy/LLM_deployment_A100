Author: Claude (independent reviewer subagent) · 2026-09-22 · Read-only source analysis against `src/sglang/python/sglang/srt` (v0.5.20 @94602c9). No servers or GPUs used. Paths below are relative to `src/sglang/python/sglang/srt` unless they start with `build/`.

## Items checked and found correct (D1)

- `role_split` is bound on every path that reaches the use. It is assigned before the first possible `return` that follows `total_tokens`. Earlier returns (`prefill_max_requests`, ignore_eos with the cache disabled → `add_one_req_ignore_eos`, `NO_TOKEN`, select/delayer/load-back `OTHER`) all exit the function. dllm and `add_one_req_ignore_eos` never call the hook. With the radix cache enabled, ignore_eos requests take the normal path, so the hook does apply to the benchmark's `ignore_eos=true` requests.
- Returning `OTHER` after commit: `scheduler.py:3954` treats `req is adder.can_run_list[-1]` as "added", so the mamba slot is not freed. `batch_is_full` is set only on `NO_TOKEN`. `alloc_group_end()` still runs after the break. The delayer was already negotiated with `local_prefillable=True` before commit.
- Single-chunk invariant: the hook checks both `has_chunked_req` (the value from after `add_chunked_req`) and `self.new_chunked_req`. The assert at `scheduler.py:3986` holds.
- Continuation: the next round calls `add_chunked_req`. `init_next_round_input()` without a tree does not re-match. The final chunk is charged `min(max_new, CLIP)` (`:1188-1192`) and gets no second mamba gap (`holds_mamba`). `max_new_tokens=0` in the split admission matches the stock chunk path (`:1597`), so retract, logprob and `prefill_finished_time` all follow stock chunk semantics (`inflight_middle_chunks`).
- Tracking: the first chunk ends at `prefix+split_len`, which is the last position and 64-aligned, so the state is read from `last_recurrent_state`. `cache_unfinished_req` caps the insert at `mamba_last_track_seqlen` (`components/mamba.py:533`), i.e. node `b`. The continuation tracks at `b + ⌊(L−b)/grid⌋·grid`, the same absolute end as stock. `split_len < end_aligned_len` guarantees `L−b ≥ grid`, so the tail mask is true.
- `mamba_branching_seqlen` is reassigned on every `init_next_round_input` (`schedule_batch.py:1595-1606`), so the conservative skip does not use a stale value. `supports_mamba()` exists on `UnifiedRadixCache` (`:3412`), `MambaRadixCache` and the base class.
- Requests shorter than 2·grid are always skipped (`end_aligned ≤ grid ≤ split_len`). The hook depends only on ids and env, so it is deterministic across TP ranks, which `@rank_consensus` on `cache_unfinished_req` requires.
