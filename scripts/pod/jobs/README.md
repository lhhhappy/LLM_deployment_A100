# 实验任务脚本

这里存放可复跑的实验配置，不维护“当前任务”副本。**正在运行、已排队和撤回的编号只看 [实验队列](../../../notes/queue.md)**；已完成结果和证据看 [实验记录](../../../notes/experiments.md)。部署与归档方式见 [Pod 操作说明](../README.md)。

每个任务须固定引擎提交 `G_COMMIT`、有效机制 `G_EXPECT`、数据集与哈希、N、派发窗口和预热/flush 流程。基线对照一次只改一个明确变量；组合实验按组合解释。短时派发后排空可做机制筛选，完整成绩须全量回放并由原 harness 判分。

历史任务脚本即使仍在目录里，也不表示已入队；重跑前核对当前数据、镜像、Pod 容量与[任务状态](../../../notes/queue.md)。脚本的原始版本及运行收据可从对应 Git 提交和 `evidence/L<编号>-<名称>/` 追溯。
