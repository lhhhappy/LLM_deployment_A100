Run a command in an inference service pod (one-shot; -i for an interactive terminal)

Usage:
  trisol inference exec <id|name> [-- <cmd...>] [flags]

Flags:
      --container string   target a specific container (defaults to the pod's main container)
  -h, --help               help for exec
  -i, --interactive        open an interactive terminal session in the pod (kubectl-style -t is taken by --team; use -i)
      --pod string         target a specific pod (defaults to the service's first Running pod)

Global Flags:
      --as-admin         act with the explicit platform-admin hat (X-As-Admin): cross-team operations and platform-wide views; non-admins get 403
      --debug            verbose diagnostics; today equivalent to --trace
      --no-color         disable colored output
      --no-input         forbid interactive prompts; commands that need input fail fast
  -g, --org string       org id/slug/display-name scope (platform admin: target/switch org via X-Org-ID; non-admin: ignored)
  -o, --output string    output format: table|json|yaml (default table)
  -p, --profile string   config profile name
      --quiet            suppress informational stderr output
      --server string    trisol server URL (one-shot, never written back; overrides TRISOL_API_URL and config)
  -t, --team string      team id or name (overrides TRISOL_TEAM and config.current_team)
      --trace            trace every HTTP request (method/path/status/duration) on stderr
      --verbose          alias for --debug
