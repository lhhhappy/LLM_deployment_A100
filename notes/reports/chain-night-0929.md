# 09-29 夜间：N42 chain 单变量筛选

作者：Codex。状态：五组已入队，运行库发布成功并恢复领取；首组测量状态见队列。没有新增正式提交。

目标是减少高并发下的 chain 超时，保持解码间隔策略不变。47266 官方 N42 已通过；平台没有给出下一失败档的明细，不能断言 N46 只卡 chain。本轮只做同配置底座、同并发的相对比较，不把本地窗口判定当正式并发上限。

## 固定项与顺序

底座直接复制 47266 的冻结 submission.json：0928c / bf6b66fa，TP8、MTP 关闭、池 400、max-running 48、BF16 KV、HiCache 64、118 / 分片 / MoE 调参 / KDA 全保留。间隔固定 configured=2、risk=1、backlog override=0。沿用 v5g-tail-rot150、rep16-v1、原 harness 和清缓存流程，数据哈希见 manifest（本地归档：`../../evidence/chain-night-0929/manifest.json`）。

五组均 N42，每组派发 3600 秒并排空；共 5 小时测量，另加启动、冒烟和排空时间。TP8 性能测量串行，已闭合日志分析可并行。

| 顺序 | 相对底座唯一研究因素 | 要回答的问题 | 主要代价 |
| --- | --- | --- | --- |
| A1 | 无，47266 原配置 | 建立当前 N42 同 ID 基准与坏例时间分解 | 必要对照 |
| B | 冷块 16k→24k；chunked-prefill-size、max-prefill-tokens、SCHED_COLD_CAP、BACKLOG_COLD_CAP 一起设 24576 | 减少长 prefill 分块次数后，入批到首 token 是否缩短、chain 是否少超时 | 单块更久，TPOT/fast 可能退化；24k 可能离开已有 MoE 调优形状范围 |
| C | SCHED_SHORT_TOKENS 2048→1024 | 缩小有缓存短请求的特殊准入范围，是否给长头更多计算机会 | 1025–2048 token 的续请求可能更慢；该旋钮也影响 prefix readiness，不能称仅改变留位量 |
| D | PARK_MAX_ROUNDS 8→2；MAX_S 仍为 2 秒 | 减少长续算连续让路，是否降低大头完成时间 | 等待中的小头可能更晚执行；必须逐 ID 看新增 chain 坏例 |
| A2 | 完整重复 A1 | 检查时间漂移、同配置噪声，避免把一两条变化当稳定收益 | 不另改任何参数 |

B 是一个冷块尺寸实验，需四个配置字段同步才会实际生效；不能把它描述成只改一个环境变量。C、D 各改一个环境变量。所有旋钮均由冻结引擎现有代码解析，本轮不开发新内核。

## 执行前与分析要求

- 每臂核验配置、代码和数据哈希，真实权重冒烟通过再测量；记录实际块大小分布。24k 若被其他预算截小、没有出现目标形状，记为因素未命中，不能宣称验证了 24k。
- A1 先查已有停车、前缀及调度计数。D 若基线从未连续让路超过两轮，跳过 D，保留 A2；不为了凑五小时运行无效旋钮。计数无法分辨时记未知，不能把未观测当未触发。
- 拆开 chain 排队时间与入批后执行时间，分别列开场/稳态及 session_start、切段 intra、turn_start、reset。缺少服务日志时间戳时不能虚构分解。
- 每臂保存 raw、派发与排空收据、完整性、错误、显存/KV/状态槽高水位、驱逐/回载可用计数和服务日志。瞬时采样峰值不是精确最大值；没有回载字节计数就注明不可测。
- 先看与 A1、A2 的共同 ID：chain 修好、新坏、未覆盖数量及每条差值；再列四类 TTFT 超标/允许、p95、TPOT 均值/p95、完成数和吞吐。所有臂都有的 ID 子集只用于公平诊断，同时保留全集结果，不能靠筛选丢掉坏例。
- 原评分门不变；TPOT p95≤100ms，fast/overall/turn 均保留。参考 ID 不完整时，不称完整不退化。任何新坏 chain 须排查且不得直接晋级；链尾变快但超标条数不变只能算余量改善。
- 24k 若 OOM、冒烟失败或请求错误，留证并终止该臂，恢复底座继续。性能差但服务正常则完成窗口；不选择性截断坏时间段。

## 去重与后续决策

今天已有 N34/N38 的 cold12k、short4096+cold12k、126 和池320；本轮不重跑这些配置，也不继续间隔/MTP。现有 fast 两轮清单与夜间脚本中未找到上述三个新变体的同底座 N42 结果；这不等于所有历史机制都从未测试。
